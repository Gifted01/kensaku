# Kensaku по-русски

Что в этой версии сделано для русского языка и русской Windows.

## Интерфейс

Весь интерфейс, мастер первого запуска и меню в трее переведены. Язык берётся из системы,
его можно сменить в **Настройки → Общие → Язык интерфейса** или кнопкой **RU/EN** в мастере
первого запуска. Меню в трее меняет язык после перезапуска.

## Поиск

- **Морфология.** Слова ищутся по основе: «договоры» находит «договора», «лицензия» —
  «лицензий». Буквы «ё» и «е» не различаются. После обновления индекс один раз
  перестраивается сам. Ограничение алгоритма Snowball: беглые гласные он не
  восстанавливает («поставок» и «поставка» — разные основы).
- **Запросы обычными словами:** «скриншоты за прошлую неделю», «последний счёт»,
  «самые большие видео в загрузках», «отчёт 3 дня назад», «акт в прошлую пятницу»,
  «презентации», «таблицы больше 5 мб». Под строкой поиска видно, как запрос понят,
  каждую часть можно убрать кликом.
- **Имена файлов** ищутся без учёта регистра: «договор» находит «Договор.pdf».

## Текст на картинках (OCR)

- PP-OCRv6 по умолчанию **не читает кириллицу**. На русской системе по умолчанию выбран
  **Indra OCR**, который читает русский.
- Tesseract докачивает русский язык (`rus.traineddata`) и распознаёт `rus+eng`.
- Файлы и профили с русскими именами (например `C:\Users\Владимир\…`) работают и на
  английской Windows.

## Поиск по смыслу

Стандартная модель понимает только английский. Для русского включите
**Настройки → Поиск по смыслу → Многоязычная модель** (potion-multilingual-128M,
около 530 МБ, в памяти около 130 МБ). Модель начинает работать после перезапуска,
при этом индекс один раз пересчитывается.

## Для разработчиков

- Строки интерфейса оборачиваются в `t("English text")` / `tn(n, "one", "other")` из
  `src/i18n`, перевод — в `src/i18n/ru.ts`. Проверка полноты: `node tools/check-i18n.mjs`.
- Тесты русского поиска: `cargo test --test russian_set`.
